# 🌈 Kiddo World

**Learn, Play, and Explore!**

Kiddo World is an interactive educational website designed to make learning fun for young children. Built with React, it combines colorful activities, simple quizzes, audio support, and creative play to encourage children to explore basic concepts in an enjoyable way.

## ✨ Features

- 🔤 **ABC Adventure** — Explore letters and learn the alphabet.
- 🔢 **Number Garden** — Practice basic numbers and mathematics.
- 🐾 **Animal Friends** — Discover animals through interactive learning activities.
- 🎨 **Color Studio** — Enjoy creative drawing and coloring activities.
- 🧸 **Toddler Playground** — Explore letters, count apples, learn colors, identify animals, and play matching games.
- 🔊 **Audio Support** — Listen to spoken words using browser text-to-speech functionality.
- ⭐ **Star Rewards** — Earn stars and track progress through activities.
- 📱 **Interactive Interface** — Enjoy a colorful, child-friendly learning experience.

## 🛠️ Technologies Used

- **React** — Building the user interface
- **JavaScript** — Interactive functionality
- **Vite** — Development server and build tool
- **Lucide React** — Icons
- **CSS** — Styling and layout
- **Browser Web Speech API** — Spoken learning support

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/kiddo-world.git
   ```

2. Navigate to the project folder:

   ```bash
   cd kiddo-world
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

**Windows PowerShell tip:** If PowerShell blocks `npm`, use `npm.cmd install` and `npm.cmd run dev` instead.
